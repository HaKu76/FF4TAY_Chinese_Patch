## 二、地图系统（398 张 + 398 元数据）

文件：`files/NAVIMAP/`

### .nmi 元数据结构（每文件 360 字节 = 90 条记录）

| 记录 | 含义 | 示例 |
|------|------|------|
| [0] | 连接点数 | 4（4 个出入口） |
| [1] | 地图 ID / 坐标 X | 54722562 |
| [2] | 坐标 Y | 1507952 |
| [3] | 方向/边界 | 65533 |
| [5-6] | 地图尺寸 | W×H |
| [7-12] | 连接点坐标 | 各连接点的 X,Y 偏移 |
| [52-57] | 额外数据区 | 宝箱、隐藏道具坐标 |

### 地图命名规则

| 前缀 | 区域 | 数量 |
|------|------|------|
| d00_* | 世界地图 | ~12 张 |
| d01_* ~ d09_* | 主线场景 | ~180 张 |
| d10_* ~ d29_* | 支线/迷宫 | ~200 张 |

## 四、道具列表（中文）

文件：`zh_CN.lproj/item.msd`（28,496 字节）

MSD 格式编码，使用 UTF-16 字符。可用 Nintendo DS 工具 `Tinke` 直接查看完整道具名称。

道具参数：`files/item_parameter.bbd.lz`（LZ77 压缩）

## 五、提取工具

| 工具 | 用途 | 下载 |
|------|------|------|
| dsdecmp | LZ77/LZ11 解压 `.lz` 文件 | `github.com/Barubary/dsdecmp` |
| Tinke | 查看 `.msd` `.nmi` `.NCBR` | `github.com/pleonex/tinke` |

### 解压命令

```bash
# 解压 LZ 文件
dsdecmp.exe -d monster.chaindata.lz monster.chaindata.bin

# 查看 MSD 文件
Tinke.exe item.msd
```
